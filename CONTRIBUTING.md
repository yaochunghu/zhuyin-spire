# Contributing

Bug reports and focused feedback are welcome through GitHub Issues. Before
posting, remove names, learner records, saved browser data, and identifying
screenshots. Use short fictional nicknames in examples.

Security or privacy vulnerabilities must be reported privately using the process
in [SECURITY.md](SECURITY.md).

The source is public for inspection, but the project is not open source and is
not currently accepting code or asset contributions. No license is granted for
redistribution or derivative publication.
