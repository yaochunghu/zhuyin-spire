# Privacy Notice / 隱私權說明

Effective: 2026-07-22

## 中文（繁體）

注音之塔是一款沒有帳號系統或應用程式後端的瀏覽器遊戲。遊戲進度、
設定、學習紀錄與暱稱只儲存在目前瀏覽器的 `localStorage`。請只使用簡短
暱稱，**不要輸入兒童或任何人的真實姓名**。

本遊戲不使用廣告、分析工具、追蹤 Cookie、指紋辨識或麥克風。語音功能
只會把遊戲內已寫好的詞語交給瀏覽器的語音朗讀服務；不同瀏覽器或作業
系統可能以不同方式處理語音服務，請參閱其供應商的隱私說明。

網站由 GitHub Pages 託管。GitHub 可能為了安全、維運及服務提供而處理
一般連線資料（例如 IP 位址與請求紀錄）。詳情請參閱 GitHub 的隱私聲明。

資料會保留在該瀏覽器，直到您清除網站資料，或在遊戲的「選項 → 隱私與
資料」選擇「清除所有遊戲資料」。這個按鈕只刪除注音之塔自己的資料。
資料不會由遊戲同步或傳送到其他裝置。

目前網址是 `https://yaochunghu.github.io/zhuyin-spire/`。未來改用自訂網域
時會從全新資料開始，不提供匯入或匯出，避免意外搬移兒童相關紀錄。

回報隱私或安全問題時，請使用 GitHub 的私人 Security Advisory，不要在
公開 Issue 貼出姓名、學習紀錄、儲存資料、畫面截圖或其他個人資訊。

## English

Zhuyin Spire is a browser game with no accounts and no application backend.
Game progress, preferences, learning history, and nicknames are stored only in
this browser's `localStorage`. Use a short nickname and **do not enter a child's
or anyone else's real name**.

The game uses no ads, analytics, tracking cookies, fingerprinting, or microphone.
Speech features send only fixed, authored game words to the browser's text-to-
speech service. Browsers and operating systems may implement that service
differently; consult the provider's privacy notice.

The site is hosted by GitHub Pages. GitHub may process ordinary connection data,
such as IP addresses and request logs, to secure, operate, and provide its
service. See GitHub's privacy statement for details.

Data remains in that browser until you clear site data or choose **Options →
Privacy & Data → Clear all game data**. That control deletes only Zhuyin Spire's
keys. The game does not synchronize or transmit this data to another device.

The current address is `https://yaochunghu.github.io/zhuyin-spire/`. A future
custom-domain launch will intentionally start fresh; no import/export feature is
planned, reducing the risk of accidentally moving child-related records.

Report privacy or security problems with a private GitHub Security Advisory.
Never post names, learning records, saved data, screenshots, or other personal
information in a public Issue.

This notice may change when the product's data practices change. Material
changes will be described in the repository changelog.
