Physical-device gate for [PLAYTEST_GATE.md](../PLAYTEST_GATE.md). One copy per device. An adult runs this alone; the learner joins later in [FAMILY_SESSION.md](./FAMILY_SESSION.md).

這一份給陪玩的大人。人在手機上看就做得到，不用會寫程式。每一台機器各做一次：iPhone 的 Safari、iPad 的 Safari、Android 手機的 Chrome。三台都通過，這道關卡才算過。

做完把結果抄進 [sessions/TEMPLATE.md](./sessions/TEMPLATE.md)。不要寫孩子的真名、學校、照片或聲音。

## 1. 語音與完整注音

對照：Mandarin and full casting。語音聽得懂；沒拼完或不對的答案不會施放；完整且正確的答案會施放。

1. 點標題的大 ▶️（不是 📚）。下一頁點「共鳴武者」（寫著可遊玩）。其他角色寫「設計中」，不用點。
2. 地圖出來後，點最下面一顆亮著的 ⚔️。那一場是教學。上面會寫「1 / 3」。
3. 點亮起來的盾牌。會出現注音格子。這時先不要按 💡。

4. 先聽語音。認字題（👉 拼注音）會念出詞；聽力題（👂）要按大按鈕「🔊 再聽」。把你聽到的詞寫進筆記。聽不懂、沒聲音、或念的是別的語言，這項就是沒通過。
5. 只填一部分格子，空至少一格。停兩秒。底下的 ✓ 應該是灰的，牌沒有打出去，怪物的血和你的盾都還沒因這張牌改變。
6. 按 🗑️ 清空。再把每一格都填滿，但故意填錯。有聲調列（ˊ ˇ ˋ ˙）就按錯的聲調。沒有聲調列時，最後一格改按別的符號。格子一滿，遊戲可能自己送出。這一次不要拼對。
7. 送出之後應看到 💨。畫面上可能很快閃過「💡 正確答案」。這張牌沒有發生效果：該加的盾沒加上，怪物也沒有因這張牌掉血。
8. 再出一張牌。盾牌若已經不在手上，先按 ✋，等下一回合盾牌再亮。這次每一格都對，聲調也對。沒看清拼法就按 💡，只這一次照著填。應看到 ✨ 答對了，而且盾變多或怪物掉血。
9. 黃色橫幅如果寫「此裝置沒有語音，請大人念出圖的意思」或「語音暫時無法播放，請大人念……仍需拼出完整注音」，代表語音失敗。大人念得出來只算補救，這項仍記沒通過，並寫橫幅上的字。

拼錯會把那張牌用掉，這是正常的。教學句子寫「沒關係，答案已經給你看了」也是正常的。紅心少一點點也正常。按鈕全部點不了、教學走不完，才是沒通過。

## 2. 語音被打斷

對照：Interrupted audio。沒有疊在一起或上一題的語音，也不會自己施放。回來後「再聽」有用，或大人看得到可念的提示。

等畫面上有「🔊 再聽」再做。第一題如果是 👉 認字、沒有再聽，先把教學打完，下一張牌或下一場再做。

題目還開著、格子先不要填滿的時候：

1. 讓它開始念。念到一半按電源鍵把螢幕鎖上，再解鎖，回到遊戲。
2. 再讓它念。這次滑回主畫面，打開時鐘或相機，再回到 Safari 或 Chrome。
3. 題目應該還在。格子不該自己送出，牌不該自己打中怪物。
4. 按一次「🔊 再聽」。應再念現在這一題，只念一遍，不要兩段聲音疊在一起，也不要念成上一張牌的詞。
5. 再聽沒有聲音時，畫面上要有請大人念的黃橫幅，而且仍然要拼完整才算對。這樣可以記通過，筆記寫「靠大人朗讀」。兩段都沒有，記沒通過。

瀏覽器若在切換時整頁自己重載、題目消失，記沒通過，寫下發生了什麼。那和第 5 項「你故意重新整理」不是同一件事。

## 3. 觸控與轉向

對照：Touch and rotation。左右滑不會出牌；故意往上拖會出牌；旋轉之後進度還在，按鈕按得到。

在戰鬥裡、注音畫面關掉之後：

1. 手指按住一張牌，沿著牌列左右滑。牌列可以跟著動。不該因此打開注音，也不該打出那張牌。牌很少、一排放得下、滑不動，可以；等牌變多再試一次左右滑。左右滑一下就出牌，記沒通過。
2. 點一下亮著的牌，或把攻擊牌明顯往上拖到怪物身上、把盾牌往上拖到自己身上。應打開注音。這是有意出牌。
3. 另出一張牌時，手指往下拖再開掉。不該出牌。
4. 戰鬥還開著時，把手機或平板轉橫、再轉直。紅心、怪物、手牌都還在，☰、✋ 和牌都按得到。
5. 打開注音、先填一格，再轉橫、轉直。那一格還在，沒有自己送出。轉回來之後仍能繼續點符號。

## 4. 暫停

對照：Pause ownership。選單開著時，連同切換到別的程式再回來，計時都停著；不會在背後自己送出。選單關掉才繼續。

1. 再進入注音，先填一格，不要填滿。
2. 按 ☰。應看到「⏸️ 注音暫停」和「遊戲已停在這裡」。
3. 選單開著，切去別的程式再回來，必要時鎖螢幕再解鎖。選單還在。底下的注音沒有自己送出。
4. 按「▶️ 繼續玩」。剛才填的那一格還在。
5. 語音若再念，只念現在這一題。不要兩段疊在一起。
6. 選單裡的這句是給大人看的，對了就好：「進度在房間之間儲存；關閉或重新整理會回到上次存檔，戰鬥與作答中不存檔。」

☰ 若變成 ⚠️，並寫進度無法儲存，記沒通過。不要為了這件事去清瀏覽資料。

## 5. 存檔與重新整理

對照：Checkpoint recovery。獎勵或地圖重新整理後還在。戰鬥中重新整理會回到上一處安全畫面，不是把整趟進度弄丟。

做完一場戰鬥，等到畫面上寫「選一張」（🎉、⭐ 或 💎 都可以）。慶祝動畫還在時先不要重整。先不要點牌。

1. 寫下紅心和金幣，例如 `28/40`、`16`。也看一下三張牌的圖。
2. 重新整理，不要清資料。
   - iPhone／iPad Safari：點位址列裡的重新載入。或關掉這個分頁，再用同一個 Safari 打開同一個網址。
   - Android Chrome：點重新載入。或關掉分頁再開同一個網址。
3. 標題應仍是測試暱稱。按鈕底下的小字會寫「▶️ 繼續」。點那個大 ▶️，不要點 🆕。🆕 會把這一局蓋掉，這項就要重做。
4. 應回到剛才的「選一張」，紅心、金幣、三張牌相同。
5. 選一張牌或按「⏭️ 跳過」，回到地圖。再寫一次紅心和金幣，用同樣方式重新整理，再按 ▶️。應回到地圖，數字相同。亮著的圓圈還能點。
6. 點一場新的戰鬥。打到一半、注音可以開著，重新整理。
7. 再按大 ▶️。應回到地圖（上一處安全畫面），不是停在剛才那一擊，也不是「再試一次」。紅心和金幣回到進這場戰鬥之前；戰鬥裡扣掉的血不保留。剛才那間亮著的房間可以再進去。整趟塔還在。

整趟不見、變成別的小玩家、或回到空的標題而且沒有繼續，記沒通過。

## 6. 螢幕閱讀、字體、縮放、減少動態

對照：Accessibility。名稱聽得懂，彈出的視窗把焦點留在裡面，關掉之後焦點回到能玩的地方，沒有關不掉或按不到的按鈕。不順的地方照實寫，能玩完就可以通過。關不掉、或主按鈕按不到，才是沒通過。

做完每一小項，先把那個系統設定關回原狀，再做下一小項。全部做完也要確認已經關回，孩子之後玩的是平常的畫面。

### 6a. VoiceOver 或 TalkBack

先設好「關得掉」的捷徑，再打開。

- iPhone／iPad：設定 → 輔助使用 → 輔助使用快速鍵，勾「旁白」（VoiceOver）。側邊或頂端按鈕按三下開，再按三下關。開著時：右滑移動，點兩下啟動。
- Android：設定 → 無障礙 → TalkBack。很多手機按住兩個音量鍵可以開關。右滑移動，點兩下啟動。菜單名稱依手機而定。

然後：

1. 打開 ☰。手指只應在這個選單裡移動：繼續玩、音量、完整選項。戰鬥中還有「🃏 查看牌組」。不該跑去按到後面的牌。
2. 啟動「▶️ 繼續玩」。焦點應回到 ☰，遊戲能繼續。
3. 再打開 ☰ →「⚙️ 完整選項」。移動時留在選項裡。按 ✕（讀出來是「關閉選項」）。焦點出來，遊戲沒被亂改。
4. 戰鬥或地圖時打開 ☰ →「🃏 查看牌組」。能聽到牌。按「✅ 完成」。回到遊戲後仍能出牌。
5. 打開注音。符號鍵應讀出那個符號；聲調讀出「聲調」加上符號。也要找得到「送出」。有再聽時，讀出來是「再聽一次」。

讀成沒有意義的「按鈕」、或你出不了這個視窗，記沒通過。字小但聽得懂，寫進限制，仍可通過。

## 7. 生命歸零

對照：Death。紅心歸零這趟結束，不能把輸掉的那一局繼續下去。

這一步放在最後，由大人操作。注音要還在：出牌仍會進到拼注音，不能靠任何測試開關跳過。

1. 進入一場普通戰鬥。不要出盾。可以故意拼錯，或拼對攻擊牌之後按 ✋。
2. 一直按 ✋，讓怪物打你。紅心 ❤️ 應慢慢減少。起始大約是 40，小怪物一次只打幾點，可能要幾分鐘。血完全不掉，記沒通過。
3. 血到 0 時應看到「💫🥋」和「再試一次！」，大人的字是「小武者只是累了，休息後再挑戰」。
4. 先按 🏠 回標題，先不要按失敗畫面上的大 ▶️。按鈕底下的小字不該再寫「繼續」，也不該有 🆕。只剩大 ▶️ 和 📚。那表示輸掉的一局沒有被存下來。
5. 再按大 ▶️。應進入「🥋 選角色」，不是剛才那場血量是 0 的戰鬥。
6. 另一種也算通過：在失敗畫面直接按大 ▶️，一樣進入選角色。做了第 4 步就不必再死一次。
