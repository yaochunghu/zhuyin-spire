# 裝置檢查表（第一關）

Parent sheet for Gate 1. Run it once on iPhone Safari, once on iPad Safari, and once on Android Chrome. Debug cast skip stays off. Leave personal browser data in place.

Blocking failures: a cast that succeeds without the full syllable, a sideways hand scroll that plays a card, a lost stable save, a focus trap that stops play, or a tutorial that cannot be finished. Record other limits and keep going.

The steps below are the phone sheet. Tick a copy of [sessions/SESSION_RECORD.md](sessions/SESSION_RECORD.md). One phone, one note. The public site is <https://yaochunghu.github.io/zhuyin-spire/>.

---

## 這份表怎麼用

孩子不用在場。一台裝置大約 40 分鐘。七項都做完再換下一台。

用記事本複製 [紀錄表](sessions/SESSION_RECORD.md)，在記事本裡勾。遊戲開在 Safari 或 Chrome，清單用 App 切換對照。不要改網站上的這份文件。

愛心快沒了就先到營火按 ❤️，把「生命歸零」留到最後一項。中途真的歸零也可以，先把失敗畫面記進第 7 項，再開一趟把還沒做的項目補完。

## 畫面上的按鈕

- 右上角 **☰**：選單。變成 **⚠️** 代表這次進度存不起來。
- **▶️**：開始。有進度時，按鈕下面的小字會寫「繼續」。**🆕** 是新遊戲，會蓋掉這個小玩家這一趟。
- **📚**：練習室。這份檢查不用。
- **✋**：這一回合結束。
- **🔊 再聽**：再念一次。
- **💡**：顯示完整拼法。教學關可以重複用。一般戰鬥一場一次。
- **⌫**：拼錯一格時倒退。
- **👨‍👩‍👧**：家長提示。手機上常常收起來，點一下才看得到字。
- **❤️**：生命。到 0，這一趟結束。
- **🪙**：金幣。

選單開著時，你會看到 **⏸️** 和「遊戲已停在這裡」。注音進行中，標題是「注音暫停」。

## 開始前

1. 用 **Safari**（iPhone、iPad）或 **Chrome**（Android 手機）打開公開網站。用一般分頁。
2. 確認畫面上沒有 **🐛**。點 **☰**，選單裡也沒有「測試工具」。看得到的話就停下來，改開公開網站再測。
3. 把聲音打開。iPhone 側邊開關撥到響鈴。點 **☰**，音量選 **🔊 大**，再按 **▶️ 繼續玩** 關掉選單。
4. 裝一個台灣國語語音，並把名字記下來。
   - iPhone／iPad：設定 → 輔助使用 → 朗讀內容 → 聲音 → 中文。下載國語（台灣），名稱常常是 **美佳**。路徑不一樣時，在設定裡搜尋「美佳」或「國語」。
   - Android：設定 → 系統 → 語言和輸入 → 文字轉語音。安裝 **中文（台灣）**。手機廠牌不同，路徑會不同。把你找到的語音名稱寫進紀錄。
5. 點標題上的名字（小字寫「切換小玩家」）。
6. 看得到 **＋ 新增** 就輸入暱稱 **測試**，選一個圖示，按 **＋ 新增**。點 **測試** 那一列，讓它成為目前的小玩家。按 **✕** 關閉。
7. 看不到 **＋ 新增**，代表四位小玩家已經滿了。不要刪除任何人，先問當初設定這台手機的大人。
8. 標題上的名字應是 **測試**。按 **▶️**。若小字寫的是「繼續」，改按 **🆕**，讓教學關重新出現。**🆕** 只影響 **測試** 這個小玩家。
9. 選角色時點 **共鳴武者**。
10. 選項最下面如果有清除資料的按鈕，不要按。也不要到系統裡清除這個網站的資料。

## 1. 國語與完整注音

教學關會一步一步亮牌。跟著亮起來的牌和畫面上的 1／3、2／3、3／3 做完。

1. 點亮起來的 **🛡️**。進入注音畫面。
2. 格子不要填滿。少留一格，等兩秒。畫面應停在注音，牌還在。
3. 需要看答案時按 **💡**。記一下完整拼法，含聲調。
4. 把格子填滿，但最後故意拼錯。有「聲調 ˊ ˇ ˋ ˙」那一列時，點錯聲調。這一題沒有聲調列時，點錯一個符號。格子一滿，遊戲會自己送出。
5. 你應看到 **💨**。這張牌用掉了。錯誤答案沒有打出效果。
6. 再點一張亮起來的牌。這次照正確拼法填滿，含聲調。一聲通常不標聲調，格子裡就不要多加聲調。
7. 你應看到 **✨**。牌的效果這時才發生。
8. 繼續把教學關打完，直到你可以自己操作，或這場戰鬥結束。
9. 認字題（畫面上有國字，大人念）不一定出聲。一直玩到出現 **👂** 和 **🔊 再聽**。題目剛出現時，同一個詞念兩次是正常的。聽看看清不清楚，像不像台灣國語。

## 2. 語音被打斷

做到看得到 **🔊 再聽** 的那一題再開始。

1. 讓它開始念，或再按一次 **🔊 再聽**。
2. 念到一半時按主畫面鍵，離開遊戲三秒，再回到 Safari 或 Chrome。
3. 鎖上手機，再解鎖，回到遊戲。
4. 打開另一個會出聲的 App（音樂或錄音），幾秒後回到遊戲。
5. 看拼寫區。格子應保持你離開前的樣子。牌不應該自己打出。
6. 按一次 **🔊 再聽**。詞再念一次，或出現黃字請大人念出那個詞。兩種都算這一步通過。黃字的意思是語音暫時不能播，仍然要拼完整注音。
7. 若同時聽到疊在一起的兩段語音，或回來時已經自己打出牌，這一項沒通過。

## 3. 觸控與旋轉

1. 進入一場手牌有好幾張卡的戰鬥。
2. **手機：** 手指放在手牌上左右滑。整排牌跟著移動，注音畫面保持關閉。再按住一張 **⚔️** 往上拖到怪物身上。注音畫面這時打開。**🛡️** 則拖到自己身上。
3. **iPad：** 牌如果已經全部排開，左右滑可能會拿起一張牌。把牌放回手牌或空白處，注音畫面保持關閉。再把 **⚔️** 拖到怪物、**🛡️** 拖到自己，注音畫面打開。把 iPad 有沒有橫向捲動手牌寫進紀錄。
4. 輕輕點一下牌也可能出牌。那算故意點擊。左右滑動整排手牌時打開注音，才算沒通過。
5. 戰鬥畫面上把裝置轉直、轉橫、再轉回來。愛心、手牌、**✋**、**☰** 都還在，也點得到。
6. 打開注音畫面後再旋轉。拼寫按鈕還在畫面裡。旋轉本身不會送出答案。

## 4. 暫停

1. 打出一張牌，停在注音畫面。留一格不要填。
2. 點右上角 **☰**。你應看到 **⏸️ 注音暫停** 和「遊戲已停在這裡」。
3. 選單保持開著。按主畫面鍵離開，再回來。選單還在。格子沒有自己填滿，也沒有送出。
4. 按 **▶️ 繼續玩**。答案仍停在你離開時的樣子，由你自己決定要不要填完。
5. 按下繼續之後如果再念一次同一個詞，牌仍然要等你拼完才打出。選單還開著就自己念完並送出，這一項沒通過。

## 5. 重新整理

1. 打贏一場，停在選牌畫面（**🎉 選一張**、**⭐ 選一張** 或 **💎 寶箱**），或回到地圖。把 **❤️** 和 **🪙** 的數字寫下來。
2. 重新整理頁面，或關掉分頁後再打開同一個網址。應回到剛才那種畫面，愛心和金幣相同。**☰** 保持選單圖示。
3. 再進入一場戰鬥。牌出現之後、分出勝負之前，重新整理。
4. 應回到上一處安全畫面（地圖或選牌），而不是卡在打到一半的戰鬥裡。愛心是離開戰鬥前的數字。
5. 整個進度消失、標題不再認得 **測試**、或戰鬥畫面壞掉，這一項沒通過。選單變成 **⚠️** 也記下來，這一項沒通過。

戰鬥中重新整理後回到地圖，是這款遊戲本來的設計。

## 6. 語音朗讀、大字、縮放、減少動態

先學會怎麼關掉，再打開朗讀。

**iPhone／iPad**

1. 設定 → 輔助使用 → 輔助使用捷徑 → 只留 VoiceOver。
2. 連按三下側邊按鈕，確認 VoiceOver 打開。再連按三下，確認關掉。
3. 測試時用這個三下開關。

**Android**

1. 設定 → 無障礙 → TalkBack。
2. 先確認關得掉：通常是按住音量上鍵和音量下鍵幾秒。請另一位大人陪著，避免關不掉。
3. 確認可以關掉之後，再打開 TalkBack 開始測。

朗讀打開後：

「查看牌組」在地圖或戰鬥的選單裡。注音進行中的選單沒有這一顆。先在地圖打開一次牌組，再進戰鬥測注音。

1. 用滑動移動焦點，用點兩下啟動。iPhone 是左右滑。Android 的 TalkBack 也是滑動移動、點兩下按下。
2. 打開 **☰**。焦點停在選單裡，聽得到「繼續玩」、音量、「完整選項」。不應該去按到選單後面的戰鬥按鈕。
3. 打開 **⚙️ 完整選項**。焦點留在選項裡。找到「關閉選項」並關掉。回來後遊戲還點得動。
4. 選單裡如果有 **🃏 查看牌組**，打開再關閉。焦點要出得來。
5. 進入注音畫面。移動到 **再聽**、注音按鈕、**倒退**、**送出**。再從 **☰** 離開。沒有被困住。
6. 關掉 VoiceOver 或 TalkBack。

接著看大字、縮放、減少動態。做完可以改回原來的設定。

1. 大字：iPhone 到 設定 → 輔助使用 → 顯示與文字大小 → 更大字體。Android 到 設定 → 顯示 → 字型大小，以及顯示大小。回到遊戲看選單和注音。字沒有變大時，改用兩指放大。把實際變化寫進紀錄。字沒有變大、按鈕仍點得到，記成限制，不算擋住發布。
2. 兩指把畫面放大、縮小。放大後仍找得到 **☰** 和注音按鈕。
3. 減少動態：iPhone 到 設定 → 輔助使用 → 動態效果 → 減少動態效果。Android 的開關名稱每支手機不同，可能在無障礙裡的動態或動畫。把你打開的那個開關名稱寫下來。打一張牌，確認遊戲還玩得下去。動畫若一直不停，這一項沒通過。

結果

- [ ] 通過
- [ ] 沒通過
- [ ] 這台沒做

我看到的情況：

朗讀把人困住、沒辦法繼續玩，算擋住發布。字級、縮放、動態做不到的地方寫清楚即可。

## 7. 生命歸零

先關掉 VoiceOver 和 TalkBack。

1. 用 **測試** 這個小玩家。出牌時仍會進入注音，要拼對才生效。
2. 戰鬥裡不要出 **🛡️**。按 **✋** 讓怪物打你。重複到 **❤️** 變成 0。
3. 應看到「再試一次！」和「小武者只是累了，休息後再挑戰」。
4. 按 **🏠** 回標題。
5. **測試** 的標題應是 **▶️** 開始新的一趟。不應再出現「繼續」，把你送回剛剛輸掉的那一場。

## 這一台算不算通過

下面任何一條出現，這台就擋住發布。修好後要重測那一項，相關的自動測試也要再跑。

- 沒拼完或拼錯，牌卻生效
- 左右滑動手牌就出牌
- 安全存檔不見，或重新整理後整個進度沒了
- 選單、選項、牌組或注音把人困住，沒辦法繼續玩
- 教學關做不完

其他奇怪的地方寫進紀錄，標成「記下就好」或「下次再看」。
