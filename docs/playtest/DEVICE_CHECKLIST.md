# 手機與平板檢查表

這一份給陪玩的大人。請在手機上逐項做，不需要會寫程式。

每一台裝置各填一份：iPhone 的 Safari、iPad 的 Safari、Android 手機的 Chrome。一台通過，不代表另外兩台通過。

對照的通過標準在 [PLAYTEST_GATE.md](../PLAYTEST_GATE.md) 的 Physical-device gate。結果寫進 [sessions/TEMPLATE.md](sessions/TEMPLATE.md) 的副本。方框在手機上若不能勾，就在紀錄裡寫「通過」或「不通過」。

請照下面的順序做。**生命歸零放在最後**，因為那一趟爬塔會結束，不能再用來測存檔。

## 1. 語音，以及必須拼完整

目標：聽得懂；沒拼完不會自己施放；拼錯不會算成功；拼對完整注音（含聲調）才成功。

1. 點大按鈕 ▶️ 開始。選「共鳴武者」。
2. 第一場是教學。跟著發亮的提示：先盾、再 ✋「結束回合」、再攻擊。教學戰鬥裡也要拼注音。
3. 出現注音畫面時，先看是哪一種：
   - 有空格（· · ·）：這題用來測「沒拼完」。
   - 只有幾個大按鈕、點一下就送出：這題只能測拼錯和拼對。沒拼完的測試改到下一張有空格的牌。
4. 沒拼完：只點一個符號，等約五秒。不該自己送出，也不該回到戰鬥。再用 ⌫ 刪掉。這時還停在同一題。
5. 拼錯：同一題或下一題，把空格填滿，但聲調故意點錯（ˊ ˇ ˋ ˙ 擇一錯的）。填滿後會自己送出。應該看到魔法散掉（💨），牌的效果沒有發生。這是失敗，不是答對。若這題的按鈕裡沒有錯誤聲調，換下一題再試。
6. 拼對：用還沒打出去的下一張牌。依序點完整注音，聲調也要對。完整的意思像「爸爸」要拼成 `ㄅㄚˋ`，不能只點 `ㄅ`。以畫面上這一題的詞為準，不必特地找「爸爸」。成功時會有 ✨，盾或攻擊才真的發生。
7. 聽的題（👂，有 🔊「再聽」）：聲音要像清楚的中文。看字的題（👉）：畫面上有國字，請大人念出來，孩子再拼。

聽到「此裝置沒有語音，請大人念出圖的意思」，或「語音暫時無法播放，請大人念：…」時：照著念。孩子仍要自己拼完。語音失敗不可以變成自動答對。

## 2. 聲音被打斷

目標：回來時不會疊著舊的聲音，也不會自己施放。要再聽時，按一次就再念一次；若改請大人念，那句話也要看得懂。

找一題注音，最好是有 🔊「再聽」的。先留下至少一個空格，避免填滿後自動送出。

1. 切到手機主畫面約五秒，再回遊戲。
2. 鎖屏，再解鎖，回到遊戲。
3. 打開一個會出聲的 App（音樂或影片）幾秒，再回遊戲。
4. 看這題還在不在，牌有沒有自己打出去。
5. 有 🔊「再聽」就按一次。應該再念**現在這題**，而且只念你按的這一次。
6. 若出現「語音暫時無法播放，請大人念：…」，把引號裡的話念出來。這樣也算通過。

通過時，回來可以是安靜的，只要題目還在、沒有自己施放。兩個聲音疊在一起、念成上一題、或自己打出牌，就是不通過。

## 3. 滑動、拖牌、轉方向

目標：左右滑只會滑牌，不會施放。明確往上拖才出牌。轉方向後，同一場戰鬥或同一題注音還在，按鈕按得到。

1. 教學打完、手牌有好幾張時再測。手指按在牌上左右滑。
   - 手機上，牌列應跟著左右動，而且不出現注音。
   - iPad 上，若牌被提起來而不是整列滑動，在空白處鬆手。不該進入注音。
2. 再把一張牌明顯往上拖，並放到目標上才鬆手：攻擊牌放到怪物上，盾牌放到小武者身上。應該打開注音。只往上提起、在半空鬆開，可以不出牌。點一下出牌是平常玩法；這一項是在確認「左右滑」不會施放、「放到目標上」才會。
3. 戰鬥中把手機轉橫、再轉直。生命、怪物和 ☰ 都還在，沒有自己跳回標題或地圖。
4. 注音畫面再轉一次橫直。同一題還在，符號按鈕和 ☰ 按得到。只轉方向不該自己送出答案。

## 4. 暫停時不能自己送出

目標：選單開著、以及選單開著又切換出去時，注音都停住。兩個原因都結束以後，才由你自己完成作答。

1. 在注音畫面、答案還沒完成時，按右上角的 ☰。
2. 應看到「注音暫停」和「遊戲已停在這裡」。
3. 停在這個選單約十秒。答案不該自己送出。
4. 選單不要關。切到主畫面再回來。選單應該還在，答案仍然沒送出。
5. 按「▶️ 繼續玩」。之後才自己拼完。
6. 按繼續之後，遊戲可以再念一次**這一題**。那是恢復，不是自己出牌。牌的效果必須等你拼對才發生。

## 5. 存檔與戰鬥中重新整理

目標：獎勵畫面和地圖重新打開還在。戰鬥中重新整理會回到上一個已儲存的房間，不會把打到一半的戰鬥存下來。

1. 打完一場，停在「選一張」（🎉、⭐ 或 💎 寶箱）。記下 ❤️ 的數字和 🪙 金幣。
2. 重新整理頁面，或關掉分頁後用**同一個瀏覽器**再開同一個網址。應回到同一張選牌，數字相同。
3. 選一張或按跳過，回到地圖。記住現在亮著、可以走的位置。
4. 再重新整理一次。應在同一個地圖位置。
5. 進入下一場戰鬥。牌出現之後、戰鬥結束之前，馬上重新整理。
6. 你應該回到地圖（上一處存檔），而不是回到打到一半的那一招。生命應是進戰鬥前的數字。這樣才是通過。

## 6. 旁白、大字、放大與減少動態

目標：聽得懂按鈕是什麼；開著的視窗可以關掉；關掉之後還玩得下去。做不到的地方要寫下來。寫下來的限制不一定等於整項失敗；**卡死、關不掉、或必要按鈕沒有名稱**才是不通過。

先把字體放大、頁面用兩指放大，最後才開旁白。旁白會改變手勢，不適合和前面的拖牌混在一起測。

1. 把系統字體調大一到兩階，回到遊戲。注音鍵、✋、☰ 都要按得到，而且沒有被切掉。
2. 兩指把網頁放大。仍要能摸到 ☰ 和注音按鈕。測完把縮放恢復。
3. 打開系統的「減少動態」或「移除動畫」，打出一張牌。動畫變短或幾乎不動是正常的。牌卡住、戰鬥凍結才是不通過。測完可以關回原來的設定。
4. iPhone／iPad 打開旁白；Android 打開 TalkBack。
5. 打開 ☰。應能聽到「繼續玩」、音量、「完整選項」。選單外面的牌不該被誤觸。
6. 打開「⚙️ 完整選項」，滑過幾個選項後關掉。焦點應回到玩得下去的地方，而不是停在看不見的按鈕上。
7. 在地圖或戰鬥打開 ☰，若有「🃏 查看牌組」就打開。應聽得到牌的名字；點一張後應聽得到更完整的說明，並且可以關閉。
8. 在注音畫面滑到符號。應聽到符號本身（例如ㄅ），不是只有「按鈕」。有「再聽」時，也要聽得到它。
9. 測完關掉旁白或 TalkBack。

## 7. 生命歸零（最後再做）

目標：心心歸零，這一趟結束。不能從輸掉的那一場繼續。

1. 注音仍然要拼。不要找測試選單。
2. 教學三步驟做完之後，可以故意少出盾，按 ✋「結束回合」，直到 ❤️ 變成 0。
3. 應看到「再試一次！」和「小武者只是累了，休息後再挑戰」。
4. 按 🏠 回標題。標題下方的小字不該寫「▶️ 繼續」。沒有進度時，小字是「▶️ 爬塔」，這是通過。
5. 再按 ▶️。應進入選角色或一趟新的爬塔，而不是死掉的那一場。若小字寫著繼續，按下去也不該回到剛剛輸掉的戰鬥。

## 這台裝置的結論

下面任一項出現，這台裝置就不能算通過，需要修好再測同一段：

- 沒拼完或拼錯，牌卻成功了
- 左右滑動或暫停中，牌自己打出去
- 選牌或地圖的進度重新打開後不見了
- 旁白或 TalkBack 讓人關不掉視窗，或沒辦法繼續玩
- 教學戰鬥做不完
