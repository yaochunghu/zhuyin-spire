# 陪玩紀錄（空白表）

Copy this file into a note on the tester's phone, or save a copy outside the repository. Tick the boxes there. One copy per device for Gate 1, and one copy per family sitting for Gate 2. A sitting that finishes both gates on the same device can use one copy and fill Part A and Part B.

Do not commit filled copies. Do not write a child's real name, school, face, or account. Nickname `測試` is enough. Screenshots of the game screen are fine when they show that nickname only.

Send the finished note to Yao. The relic-content pull request waits until every required device has Part A passed and one family sitting has Part B passed through an Act I clear or a death.
