# Session records

Copy [TEMPLATE.md](./TEMPLATE.md) once per device checklist and once per family sitting. A filled file in this folder is gitignored. Keep it in a private note if it might leave this computer.

Use no identifying child information: no name, nickname the child uses elsewhere, age, school, photo, or voice. The game profile for these gates is a test nickname such as `測試`.

The release rules stay in [PLAYTEST_GATE.md](../../PLAYTEST_GATE.md). Parents follow [DEVICE_CHECKLIST.md](../DEVICE_CHECKLIST.md) and [FAMILY_SESSION.md](../FAMILY_SESSION.md).
