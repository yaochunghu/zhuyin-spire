# 家人陪玩（第二關）

One adult and the learner, through an Act I clear or a death. Allow 30–45 minutes plus breaks. Debug cast skip stays off. Use the learner's own nickname profile. Gate 1 on the device they will play should already be free of blocking issues.

Yao's decision: this session and the three-device checklist both pass before the relic-content pull request merges. Tick [sessions/SESSION_RECORD.md](sessions/SESSION_RECORD.md) Part B. No real names.

## 給大人

你念字、看 **👨‍👩‍👧 家長提示**、幫忙拿穩裝置。孩子點大按鈕和注音。

答案由孩子拼。孩子問的時候可以再念一次題目，或在教學關按 **💡**。教學關的 **💡** 可以重複用。一般戰鬥一場只能用一次。不要每張牌都把拼法點給孩子看。

手機上的家長提示常常收起來。看到 **👨‍👩‍👧** 或「提示」就點開。

孩子說停、煩躁、或一直打哈欠，就停。這份紀錄可以寫「改天繼續」。第二關要看到第一幕結束，或看到生命歸零，才算完成。不必同一天做完，也不必爬完第二幕、第三幕。

地圖最上面的小字是：⚔️戰鬥、💀菁英、🔥休息、🏪商店、💎寶箱、🐉Boss。亮圈才可以點。地圖標題是 **第一幕 · 入門塔**。戰鬥時角落如果寫「庭園」，那也是第一幕。

## 請念給孩子聽

開場可以照這幾句說，用你平常的語氣就好。

「我們要一起爬一座塔，塔的名字叫注音之塔。你是小武者，我坐在旁邊當幫手。你點大大的按鈕，我念字給你聽。」

「拼錯會冒煙，沒有關係，我們再出下一張牌。愛心是力氣。愛心沒有的時候，小武者只是累了，這一趟就先休息。」

「你想停就說停。塔會等我們。我們可以喝水、休息，不一定要今天爬完。」

打到一半可以補這三句：

「盾牌先擋住怪的攻擊。怪頭上的圖案，是牠下一動想做的事。有劍和數字，就是要打我們。」

「注音要拼完整。像爸爸要拼 ㄅㄚˋ，不是只點 ㄅ。」

「三張牌選一張就好。你選。不想要可以跳過。」

生命歸零時：

「小武者只是累了。你已經很認真。我們可以改天再爬，也可以現在再試一次。你決定。」

## 陪玩腳本

開始前，大人自己確認：這台已經做過裝置檢查，沒有擋住發布的問題。標題上的小玩家是孩子的暱稱，不是裝置檢查用的 **測試**。聲音開著，選單音量是 **🔊 大**。畫面上沒有 **🐛**。

1. 念開場。請孩子按 **▶️**。要選角色時，說「我們選這位共鳴武者」，讓孩子點。
2. 第一場是教學。把畫面上的 1／3、2／3、3／3 念出來。孩子點亮起來的牌。拼的時候你念國字或讓孩子聽 **🔊 再聽**。孩子停住時先等一下，再問要不要再聽一次。
3. 教學結束後到地圖。說「亮亮的圈圈才可以走，我們從下面往上爬。」孩子點下一格。你可以指著 **🔥** 或 **🏪** 說那是休息或商店，由孩子決定要不要走。
4. 每一場戰鬥先指一次怪頭上的「本回合」。劍和數字是要打來的傷害，盾是怪物在防守。問孩子「我們要先擋，還是先打？」然後讓孩子出牌。**⚔️** 拖到怪物，**🛡️** 拖到自己，或直接點牌。手機上左右滑是在看手牌，往上拖才是出牌。iPad 上如果左右拖拿起了牌，放回空白處就不會出牌。
5. 選牌時說「三張選一張，或按跳過。你選。」
6. 營火有 **❤️**（大約補四成生命）、**🗑️ 刪牌**，看得到 **🔨 升級** 就讓孩子試一張：點牌、看綠色的新效果、再按確認。家長提示如果還寫升級尚未開放，照按鈕做，並把那句話抄進紀錄。
7. 商店由你念價錢。孩子可以不買。刪牌要花金幣，孩子不想刪就離開。
8. 繼續爬，直到第一幕最上面的 **🐉 Boss**，或愛心歸零。中間休息照孩子的需要。
9. Boss 打倒後先選一張牌，愛心會補滿。選完或按跳過之後，會看到「第 1 幕過關！」。第二關到這裡就可以結束。**⬆️** 會進入第二幕，這週不用為了這份表繼續點。孩子還想玩就讓他玩，紀錄寫已經打完第一幕。
10. 結束前問：「還想再玩一次嗎？」把孩子的意思記下來。

這條路沒有商店、營火、升級或寶箱時，寫「這條路沒有」。改天用另一趟補，不必在孩子累的時候硬走第二輪。

## 請觀察什麼

邊玩邊在紀錄表記幾筆就好，不必停下來填表。

- 走到哪一種房間，玩了多久
- 拼錯大概幾次
- 你幫忙拿裝置、點選單的次數
- 你直接告訴完整拼法的次數
- 滑一下就出牌、或點錯房間
- 你或孩子看不懂的牌、怪物、詞（例如易傷、勁、轉拍）
- 沒聲音、黃字、或念了奇怪的詞
- 離開幾間房間時的愛心數字
- 孩子還想不想再玩

結束前，用自己的話確認你說得出這三件事：

- 攻擊打中怪物，怪物的血會減少
- 盾先擋住傷害，盾不夠才扣愛心
- 怪頭上「本回合」的圖案是牠這一動要做的事

這三件說不出來，這一次的第二關先不要算通過。把哪一句卡住寫進紀錄。

## 這一次怎麼算

第二關通過要同時有這四件：

- 這台沒有擋住發布的裝置問題
- 看到「第 1 幕過關！」，或看到生命歸零
- 大人可以陪著完成注音，孩子仍是主要拼答案的人
- 孩子在適齡的幫忙下，點得了出牌、結束回合、地圖和選牌

反覆卡住的地方先改小地方，再增加新內容。平衡數字要超過一趟才調整。自動測試裡的教學關通過，不算第一幕平衡或學習效果通過。
