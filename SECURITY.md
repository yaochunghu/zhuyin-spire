# Security Policy

## Supported version

Security fixes are applied to the latest published `0.2.x` release and the live
GitHub Pages build. Older tags are historical snapshots and are not maintained.

## Report a vulnerability privately

Use this repository's **Security → Report a vulnerability** form:

https://github.com/yaochunghu/zhuyin-spire/security/advisories/new

Please include reproduction steps, affected browser/version, impact, and a
minimal proof of concept. Do not open a public Issue, publish an exploit, or
include children's names, learning records, browser storage, screenshots, or
other personal information.

The maintainer will acknowledge a report when practical, investigate it, and
coordinate disclosure after a fix is available. This is a small personal project,
so no guaranteed response-time SLA is offered.
